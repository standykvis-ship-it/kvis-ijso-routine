วิธีเผยแพร่ผ่าน HTTPS และติดตั้งบน iPad / iPhone / Android แบบไม่ขัดข้อง

อัปโหลดไฟล์ HTML ขึ้นโฮสต์ HTTPS แล้วเปิดผ่านเบราว์เซอร์หลักเพื่อปักหมุดหน้าจอโฮมได้ทันที

กำลังตรวจสอบโหมดใช้งาน...

1 เผยแพร่ผ่าน HTTPS

อัปโหลดไฟล์แอป kvis_ijso_routine_tracker_1_7.html ขึ้น GitHub Pages หรือ Netlify Drop เพื่อให้ได้ลิงก์ https:// หลีกเลี่ยงการเปิดผ่าน file:// หรือเบราว์เซอร์ในแอปแชท

2 ติดตั้งบน iPad / iPhone (Safari)

เปิดลิงก์ https:// ใน Safari แล้วแตะปุ่ม แชร์ (Share) → เลือก “เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)” → กด เพิ่ม เพื่อเปิดใช้งานแบบเต็มหน้าจอและแคชไฟล์ผ่าน Service Worker

3 ติดตั้งบน Android & ซิงก์ข้อมูล

บน Android ให้เปิดใน Chrome แตะเมนู ⋮ → เลือก “ติดตั้งแอป” หรือ “เพิ่มไปยังหน้าจอหลัก” และใช้เมนู ส่งออก / นำเข้า (JSON) เพื่อย้ายตาราง 1–7 วันข้ามเครื่องได้ไม่ตกหล่น

แด่เด็กชายอภิวิชญ์ ตั้งแก้ว นักเรียนกำเนิดวิทย์และผู้แทนประเทศ รุ่น 14 • KVIS & IJSO
